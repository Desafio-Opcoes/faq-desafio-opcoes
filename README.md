# FAQ Desafio de Opções

Página de perguntas frequentes para os clientes do Desafio de Opções, publicada pelo GitHub Pages.

- **Conteúdo:** conceitos básicos de opções, operação na prática, passo a passo no Bolsa Fácil e no Genial HB, Imposto de Renda.
- **Novas dúvidas:** o campo no fim da página envia a pergunta para o Google Forms "Desafio de Opções | Envie suas dúvidas", que alimenta a planilha de respostas.
- **Atualização:** as novas dúvidas da planilha são consolidadas e respondidas, e o `index.html` é atualizado neste repositório. O link do site não muda.

Material educativo. Os códigos e preços citados são exemplos e não constituem recomendação de investimento.
